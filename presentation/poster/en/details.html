What happens when you send coins

  1. The wallet signs the transaction. The signature is only valid on this network.
  2. The node checks the signature and the fee.
  3. The transaction waits in the mempool until it lands in a block.
  4. A miner looks for the right nonce for the next block.
  5. Every node checks the new block for itself.
  6. If the chain wins out, all nodes switch to it. Otherwise it stays a side branch.

Four rules that mattered to me

Most work wins

The chain with the most computing work counts, not the longest one.

All or nothing

A chain switch is fully checked first and only then applied. If one block is broken, everything stays as it was.

Limits on the clock

A timestamp must be later than the median of the last 11 blocks and at most 2 minutes in the future.

Difficulty adapts

If a block is 30 minutes late, it gets half as hard. I only use whole numbers, so every node is guaranteed to get the same result.

My mining program for Windows

A small background program with a tray icon. It uses the graphics card (CUDA) and the CPU.

6.9 GH/s

RTX 4070

measured on my own computer

Considerate

It only starts once the PC has been quiet for a while, and ramps up slowly. During games or when things get too hot, it slows down or pauses.

Double-checks itself

It runs a self-test at start, and every hit from the graphics card is recomputed on the CPU.

Being honest

  • Please don't put real money into it.
  • Nobody but me has reviewed the code.
  • I only built and tested the mining program on my own computer (Windows 11, RTX 4070).
  • Not tried yet: very long runs, the effect on games, and running it as a service.
  • On a normal PC you will practically never find a block alone. That's fine, it's about understanding for me.
